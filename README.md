# FactorEdge
**FactorEdge**, IoT cihazlarından MQTT ve Modbus protokolleri aracılığıyla gerçek zamanlı veri toplayan ve işleyen akıllı fabrika yönetim platformudur. .NET tabanlı mimarisiyle makine takibi, sensör verilerinin analizi, kamera destekli izleme ve çok kiracılı (Multi-Tenant) yönetim özellikleri sunar.
